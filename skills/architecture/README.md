# Architecture

Catalog-style skills. Each one teaches a set of design items (patterns, principles,
practices) with a reference explanation per item and, where useful, runnable examples.

Not every architecture skill uses the same language set: include only languages that
genuinely support the skill's concepts. See
[Choosing languages](../../templates/architecture-template/SKILL.md#choosing-languages)
in the architecture template, which is also the starting point for a new skill.

## Skills

| Skill                                                                                   | Description                                                                                             | Languages                                                         |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| [`design-patterns`](design-patterns/SKILL.md)                                           | Explains and applies the 23 Gang of Four (GoF) design patterns                                          | Python, C, C++, Java, C#, JavaScript, Rust, Go, PHP, Swift        |
| [`object-oriented-programming-paradigm`](object-oriented-programming-paradigm/SKILL.md) | Explains and applies OOP — classes, the four pillars, object relationships, SOLID, and design qualities | Python, C++, Java, C#, JavaScript, PHP, Swift                     |
| [`database-normalization`](database-normalization/SKILL.md)                             | Explains and applies database normal forms (1NF–5NF, BCNF) and strategic denormalization                | PostgreSQL, MySQL, SQLite, MongoDB, Cassandra, ScyllaDB, DynamoDB |
