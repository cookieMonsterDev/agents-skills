# Architecture

Skills for explaining, reviewing, and improving architecture. Each provides focused
references and concrete scenarios; runnable examples are included where useful.
Reviews connect evidence to a failure or change pressure, a minimal correction, and
a verification criterion.

Not every architecture skill uses the same language set: include only languages that
genuinely support the skill's concepts. See
[Choosing languages](../../templates/architecture-template/SKILL.md#choosing-languages)
in the architecture template, which is also the starting point for a new skill.
