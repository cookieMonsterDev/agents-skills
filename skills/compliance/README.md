# Compliance

Workflow skills that review solutions against a regulation or standard: code, system
designs, data flows and documents such as policies, contracts and papers. Each skill
grounds its checks in the official text and its regulator's guidance, and writes a
findings report with article-level citations, evidence and fixes.

These skills produce technical and documentary reviews, not legal advice. Their
conclusions speak only for the evidence reviewed, and they route decisions that need a
DPO, compliance officer or qualified counsel to those people.

## Skills

| Skill                                         | Description                                                                                           |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [`gdpr-compliance`](gdpr-compliance/SKILL.md) | Reviews code, data flows and privacy documents against the EU GDPR and writes a cited findings report |

## Conventions

- Reports go to the user's working directory or a folder they choose.
- Reports, examples and tests describe personal or confidential data by category and location, with synthetic values only.
- Requirements cite the official text (article, recital or clause) and link the authoritative source.
