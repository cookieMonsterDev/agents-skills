# Docs

Documentation-grounded skills. Each one routes a question to the right section of a
product's or framework's official documentation, searches it, and answers with direct
links to the authoritative pages.

Every docs skill has this layout:

```
skills/docs/<product>-docs/
├── LICENSE
├── SKILL.md
└── references/
    └── topic-map.md
```

Start a new one from [`templates/docs-template`](../../templates/docs-template/SKILL.md).
